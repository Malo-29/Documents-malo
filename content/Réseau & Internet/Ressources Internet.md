# 📚 Ressources Internet — FMHY & Alternatives libres

> Un catalogue personnel des ressources en ligne essentielles : sites pour trouver des livres, logiciels, médias, documentation — majoritairement gratuits, légaux ou dans des zones grises assumées.

## FMHY — Freemediaheckyeah

**[fmhy.net](https://fmhy.net)** est le wiki communautaire le plus complet pour trouver des ressources gratuites sur internet. Organisé par catégorie.

> "If it exists, FMHY has it."

### Sections clés
- **Reading** → livres, comics, manga
- **Movies / TV** → streaming gratuit
- **Music** → téléchargement, streaming alternatif
- **Software** → logiciels libres ou crackés
- **Android / iOS** → APKs, tweaks
- **Educational** → cours, MOOC gratuits
- **Tools** → outils en ligne utiles

Le wiki est hébergé sur GitHub et maintenu par la communauté. En cas de blocage : chercher "FMHY mirror" ou accéder via [[Tor]].

## Livres & Ebooks

### Anna's Archive ⭐
**[annas-archive.org](https://annas-archive.org)** — Le plus grand agrégateur de bibliothèques pirates du monde. Agrège :
- Library Genesis (LibGen) — livres scientifiques, manuels
- Sci-Hub — articles scientifiques
- Z-Library — livres généralistes
- Internet Archive — livres numérisés du domaine public

Recherche par titre, auteur, ISBN. Téléchargement en PDF, EPUB, MOBI. À ouvrir avec [[Calibre]].

### Z-Library
**[z-lib.id](https://z-lib.id)** (miroir actuel) — Bibliothèque en ligne avec compte gratuit (10 téléchargements/jour). Interface plus propre qu'Anna's Archive.

### Sci-Hub
**[sci-hub.se](https://sci-hub.se)** — Accès gratuit à quasi tous les articles scientifiques (>85 millions). Indispensable pour contourner les paywalls académiques. Coller le DOI ou l'URL de l'article.

### Project Gutenberg
**[gutenberg.org](https://www.gutenberg.org)** — Domaine public légal. +70 000 ebooks gratuits et légaux (œuvres dont le copyright est expiré).

### Internet Archive
**[archive.org](https://archive.org)** — Bibliothèque numérique légale + Wayback Machine (archives web).
