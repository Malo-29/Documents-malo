# 📝 LibreOffice

#alternatives #bureautique #open-source

> LibreOffice est ma suite bureautique libre, remplacement direct de Microsoft Office. Gratuit, open source, compatible avec les formats .docx, .xlsx, .pptx.

---

## Pourquoi LibreOffice ?

- **Gratuit et open source** — pas d'abonnement, pas de licence
- **Compatible** avec les formats Microsoft Office (.docx, .xlsx, .pptx)
- Disponible sur macOS, Linux, Windows
- Pas de compte requis, aucune télémétrie
- Géré par **The Document Foundation** (non-profit)

## Format natif : ODF

Le format natif de LibreOffice est **ODF (Open Document Format)** : `.odt`, `.ods`, `.odp`. C'est un standard ISO ouvert.

Pour la compatibilité avec des personnes utilisant MS Office, je sauvegarde en `.docx`/`.xlsx` — LibreOffice gère la conversion, avec parfois des pertes de mise en forme pour les documents complexes.

## Tips

### Raccourcis clés
- `Ctrl+Shift+S` → Enregistrer sous (choisir le format)
- `F5` → Navigateur de document (plan, titres)
- `Ctrl+H` → Rechercher et remplacer

### Writer — Mode édition compatible Word
Pour une meilleure compatibilité : *Outils → Options → LibreOffice Writer → Compatibilité* → activer les options de compatibilité Word.

### Impress — Présentation
Pour exporter en PDF : *Fichier → Exporter en PDF* avec les options souhaitées (qualité, liens, formulaires).

## Alternative en ligne : Cryptpad

Pour les documents collaboratifs, j'utilise [[Cryptpad]] plutôt que Google Docs — chiffrement de bout en bout, pas de compte Google requis.

## LaTeX plutôt que Writer pour les documents formels

Pour les devoirs, rapports ou tout document nécessitant une mise en forme précise, je préfère [[LaTeX]] — bien plus puissant que Writer pour les mathématiques et la typographie.
